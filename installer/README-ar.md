# بناء مثبّت «نوفا الجمال» (للمطوّر فقط)

## المتطلبات (مرة واحدة)
1. **Node.js 22+** مثبّت على جهازك (ينسخ المثبّت ملف `node.exe` ضمن الحزمة، فلا يحتاج العميل لتثبيته).
2. **Inno Setup 6.3+** (مجاني): https://jrsoftware.org/isdl.php
3. *(اختياري)* واجهة عربية للمثبّت: حمّل `Arabic.isl` من ترجمات Inno غير الرسمية وضعه في `installer\Languages\Arabic.isl` — يلتقطه السكربت تلقائياً.
4. مفاتيح التوقيع: `node tools\keygen\keygen.js init` (مرة واحدة فقط — **احتفظ بنسخة احتياطية آمنة من `tools\keygen\keys\private.pem`** ولا ترفعه إلى GitHub؛ من دونه لا تستطيع إصدار تراخيص).

## البناء
```
installer\build-installer.bat
```
الناتج: `installer\output\NovaAlJamal-Setup-1.0.0.exe`

الخطوات التي ينفذها السكربت: توليد الأيقونات وصور المعالج ← بناء `NovaService.exe` (خدمة Windows حقيقية) ← تجهيز الحزمة (بدون بيانات ولا مفاتيح خاصة) ← تجميع المثبّت.

## ما يفعله المثبّت عند العميل
- ينسخ البرنامج إلى `C:\Program Files\NovaAlJamal` (للقراءة فقط للمستخدم العادي) والبيانات إلى `C:\ProgramData\NovaAlJamal` (للمدير والنظام فقط).
- يسجّل خدمة Windows `NovaAlJamal` تعمل تلقائياً مع الجهاز وتُعاد تلقائياً إن توقفت.
- ينشئ اختصارين على سطح المكتب: **نوفا الجمال** و **نوفا الجمال - إدارة الترخيص**.
- أول تشغيل: معالج إعداد (اسم المنشأة، العملة، حساب المديرة) ثم فترة تجريبية 14 يوماً.

## إصدار ترخيص لعميل
1. يفتح العميل **إدارة الترخيص** وينسخ **معرّف الجهاز** ويرسله لك مع اسم المنشأة.
2. شغّل `tools\keygen\run-keygen.bat` (يفتح واجهة محلية)، أدخل المعرّف والاسم والنوع (دائم/سنوي/تجريبي) ← انسخ المفتاح وأرسله.
3. يلصق العميل المفتاح واسم المنشأة في صفحة التفعيل.

## تحديث نسخة عند عميل
شغّل مثبّت الإصدار الجديد فوق القديم: تُحدَّث الملفات وتبقى البيانات والترخيص والشعار كما هي.

## وضع التطوير
نسختك الحالية (`C:\beauty house`) تعمل بوضع التطوير تلقائياً (بياناتها بجوار الكود وبلا فحص ترخيص) لأن فيها `data\beautyhouse.db`. على جهاز تطوير جديد أنشئ ملفاً فارغاً باسم `.dev` في جذر المشروع أو اضبط `NOVA_DEV=1`.

## حدود صريحة للحماية
الترخيص المحلي يمنع النسخ العادي ومشاركة المفتاح (توقيع Ed25519 مرتبط ببصمة الجهاز)، لكنه لا يمنع مبرمجاً متمكناً يملك صلاحيات كاملة على الجهاز من تعديل الكود. لحماية أقوى للكود يلزم تحويله إلى ملف تنفيذي مُغلَّف (مثل Node SEA/تعتيم) — يمكن إضافته لاحقاً.
