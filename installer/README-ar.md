# بناء مثبّت «نوفا للتجميل» (للمطوّر فقط)

## المتطلبات (مرة واحدة)
1. **Node.js 22+** مثبّت على جهازك (ينسخ المثبّت ملف `node.exe` ضمن الحزمة، فلا يحتاج العميل لتثبيته).
2. لا حاجة لأي أداة أخرى: المثبّت مكتوب بـ WPF ويُبنى بمترجم `csc.exe` المدمج في ويندوز.
3. مفاتيح التوقيع: `node tools\keygen\keygen.js init` (مرة واحدة فقط — **احتفظ بنسخة احتياطية آمنة من `tools\keygen\keys\private.pem`** ولا ترفعه إلى GitHub؛ من دونه لا تستطيع إصدار تراخيص).

## البناء
```
installer\build-installer.bat
```
الناتج: `installer\output\NovaBeauty-Setup-1.0.0.exe` — ملف واحد يعمل على Windows 10/11 بنسخة 64 بت (يشمل أجهزة ARM)، ولا يحتاج العميل لتثبيت Node.js أو أي برنامج آخر.

الخطوات: بناء مضيفَي التشغيل (`NovaService.exe` خدمة ويندوز، و`NovaUser.exe` للتثبيت بدون صلاحيات) ← تجهيز الحزمة (بدون بيانات ولا مفاتيح خاصة) ← بناء `uninstall.exe` ← ضغط الحزمة ← بناء المثبّت.

## تصميم المثبّت
- نافذة بلا إطار ويندوز التقليدي، بحواف دائرية وخط Cairo، وافتراضياً **نهاري** مع زر للتحويل إلى **ليلي**.
- الشاشة الأولى: «تثبيت سريع» بضغطة واحدة + رابط اتفاقية الترخيص + «خيارات مخصصة».
- الخيارات: **لجميع المستخدمين** (Program Files + خدمة ويندوز + طلب UAC) أو **للمستخدم الحالي فقط** (`%LocalAppData%` بدون صلاحيات مدير)، ومسار التثبيت مع المساحة المطلوبة والمتاحة، والمكوّنات (اختصارات سطح المكتب وقائمة ابدأ، التشغيل مع ويندوز، فتح النظام بعد التثبيت).
- شاشة تقدّم بنسبة حقيقية ورسائل وصفية ونصائح متغيّرة، ثم شاشة نجاح مع «تشغيل التطبيق الآن».
- يظهر في أسفل الشاشة الأولى اسم المصمم ووسائل التواصل بشكل هادئ.

## أوامر للتثبيت الصامت (للفنيين)
```
NovaBeauty-Setup-1.0.0.exe --silent            (لجميع المستخدمين — يحتاج صلاحية مدير)
NovaBeauty-Setup-1.0.0.exe --silent --user     (للمستخدم الحالي)
خيارات: --dir "مسار" --port 5190 --no-desktop --no-startmenu --no-autostart
uninstall.exe --silent [--deletedata]
```

## ما يفعله المثبّت عند العميل
- لجميع المستخدمين: البرنامج في `C:\Program Files\NovaBeauty` والبيانات في `C:\ProgramData\NovaBeauty` (للمدير والنظام فقط)، وخدمة `NovaBeauty` تعمل تلقائياً وتُعاد إن توقفت.
- للمستخدم الحالي: البرنامج في `%LocalAppData%\Programs\NovaBeauty` والبيانات في `%LocalAppData%\NovaBeauty`، ويعمل في الخلفية عند تسجيل الدخول.
- اختصاران: **نوفا للتجميل** و **نوفا للتجميل - إدارة الترخيص**، ويُسجَّل البرنامج في «التطبيقات المثبّتة» مع إلغاء التثبيت (مع خيار حذف البيانات أو الاحتفاظ بها).
- أول تشغيل: معالج إعداد من ثلاث خطوات ثم فترة تجريبية 14 يوماً.

## إصدار ترخيص لعميل
1. يفتح العميل **إدارة الترخيص** وينسخ **معرّف الجهاز** ويرسله لك مع اسم المنشأة.
2. شغّل أيقونة **أداة ترخيص محلات التجميل** (`tools\keygen\LicenseTool.exe`)، أدخل المعرّف والاسم والنوع ← انسخ الرسالة الجاهزة وأرسلها.
3. يلصق العميل المفتاح واسم المنشأة في صفحة التفعيل.

## تحديث نسخة عند عميل
شغّل مثبّت الإصدار الجديد فوق القديم: تُحدَّث الملفات وتبقى البيانات والترخيص والشعار كما هي.

## وضع التطوير
نسختك الحالية (`C:\beauty house`) تعمل بوضع التطوير تلقائياً (بياناتها بجوار الكود وبلا فحص ترخيص) لأن فيها `data\beautyhouse.db`. على جهاز تطوير جديد أنشئ ملفاً فارغاً باسم `.dev` في جذر المشروع أو اضبط `NOVA_DEV=1`.

## الهوية والأيقونات
الشعار الرسمي في `toolsuildrand\logo.png`. لتوليد كل الأيقونات منه (دائرية للنظام، وأيقونة المثبّت، وأيقونة أداة الترخيص): `powershell -ExecutionPolicy Bypass -File toolsuild\make-brand.ps1`.

## حدود صريحة للحماية
الترخيص المحلي يمنع النسخ العادي ومشاركة المفتاح (توقيع Ed25519 مرتبط ببصمة الجهاز)، لكنه لا يمنع مبرمجاً متمكناً يملك صلاحيات كاملة على الجهاز من تعديل الكود. لحماية أقوى للكود يلزم تحويله إلى ملف تنفيذي مُغلَّف (مثل Node SEA/تعتيم) — يمكن إضافته لاحقاً.
