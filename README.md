# Beauty House — نظام إدارة الصالون

نظام محلي لإدارة صالون تجميل: نقطة بيع، حجوزات، مخزون، عميلات، وتقارير.

## التشغيل

يتطلب Node.js (إصدار 22 أو أحدث، لاستخدام `node:sqlite`). لا حاجة لـ `npm install`.

```bash
node server/server.js
```

ثم افتح: http://localhost:5173

عند أول تشغيل تُنشأ قاعدة البيانات `data/beautyhouse.db` تلقائياً مع حساب المدير الافتراضي (راجع `server/db.js`).
**غيّر كلمة المرور فوراً** من: الإعدادات > الحساب والأمان.

## البنية

- `server/` — الخادم (Node.js بدون مكتبات خارجية) ومساراته في `server/routes/`
- `public/` — الواجهات (HTML/CSS/JS)
- `data/` — قاعدة البيانات (SQLite) — **غير مرفوعة إلى المستودع**

## الأقسام

- **نقطة البيع:** منتجات الكافيه ومنتجات التجميل، طرق الدفع نقداً/بنكك/أوكاش، وإيصال حراري 80مم.
- **الحجوزات:** بطاقات الخدمات وجدول أسبوعي، مع الدفع وطباعة الإيصال من نافذة الحجز.
- **المخزون:** ثلاثة أقسام: منتجات التجميل، منتجات الكافيه، الخدمات.
- **العميلات والتقارير والإعدادات.**

## النسخ الاحتياطي

انسخ ملف `data/beautyhouse.db` فقط.
