# Beauty House — نظام إدارة الصالون

نظام محلي لإدارة صالون تجميل: نقطة بيع، حجوزات، مخزون، عميلات، وتقارير.

## التشغيل

يتطلب Node.js (إصدار 22 أو أحدث، لاستخدام `node:sqlite`). لا حاجة لـ `npm install`.

```bash
node server/server.js
```

ثم افتح: http://localhost:5173

عند أول تشغيل تُنشأ قاعدة البيانات `data/beautyhouse.db` تلقائياً مع حساب المدير الافتراضي (راجع `server/db.js`).
**غيّر كلمة المرور فوراً** من: الإعدادات > الحساب والأمان.

## البنية

- `server/` — الخادم (Node.js بدون مكتبات خارجية) ومساراته في `server/routes/`
- `public/` — الواجهات (HTML/CSS/JS)
- `data/` — قاعدة البيانات (SQLite) — **غير مرفوعة إلى المستودع**

## الأقسام

- **نقطة البيع:** منتجات الكافيه ومنتجات التجميل، طرق الدفع نقداً/بنكك/أوكاش، وإيصال حراري 80مم.
- **الحجوزات:** بطاقات الخدمات وجدول أسبوعي، مع الدفع وطباعة الإيصال من نافذة الحجز.
- **المخزون:** ثلاثة أقسام: منتجات التجميل، منتجات الكافيه، الخدمات.
- **العميلات والتقارير والإعدادات.**

## النسخ الاحتياطي

انسخ ملف `data/beautyhouse.db` فقط.

## المالية (للمديرة فقط)

صفحة **المالية** من القائمة الجانبية، وفيها ثلاثة تبويبات:

- **نظرة عامة:** الإيرادات والمصروفات والرواتب وصافي الربح لأي فترة، ورسم بياني لآخر 6 أشهر، وحركة كل وسيلة دفع (نقداً/بنكك/أوكاش: وارد وصادر وصافي)، والمصروفات حسب التصنيف، وطباعة تقرير A4.
- **المصروفات:** تسجيل وتعديل وحذف المصروفات بتصنيف ووسيلة دفع وتاريخ.
- **الرواتب والسلف:** الراتب الأساسي لكل موظفة، تسجيل **سلفة** أو **مكافأة** أو **خصم**، وصرف الراتب الشهري مع خصم السلف تلقائياً (كلياً أو على أقساط) والتراجع عن الصرف.

الأرقام على أساس النقد (ما دُفع فعلياً). السلف تُحتسب مصروفاً وقت دفعها، وخصمها لاحقاً من الراتب لا يُحتسب مرة ثانية.

## الدفع المقسّم

في نقطة البيع ونافذة الحجز زر **مقسّم**: يمكن دفع فاتورة واحدة بأكثر من وسيلة (مثلاً 18,000 نقداً + 12,000 بنكك) بشرط أن يساوي المجموع الإجمالي. تُحفظ كل دفعة في جدول `payments` وتظهر في الإيصال وتقارير الخزينة.

## التوزيع التجاري والترخيص (نوفا الجمال)

- **المثبّت:** `installer/build-installer.bat` ينتج `NovaAlJamal-Setup-x.y.z.exe` (Inno Setup) يثبّت خدمة Windows حقيقية واختصارين على سطح المكتب. التفاصيل في `installer/README-ar.md`.
- **الترخيص:** مفتاح موقّع بتوقيع غير متناظر (Ed25519) ومرتبط ببصمة الجهاز؛ التطبيق يحمل المفتاح العام فقط. أداة المطوّر لتوليد المفاتيح: `tools/keygen/run-keygen.bat`. المفتاح الخاص `tools/keygen/keys/private.pem` **لا يُرفع إلى GitHub**.
- **أول تشغيل عند العميل:** معالج إعداد (اسم المنشأة والعملة وحساب المديرة) ثم تجربة 14 يوماً.
- **الشعار:** رفع الشعار من الإعدادات يحدّث تلقائياً أيقونة المتصفح وتطبيق الويب واختصارات سطح المكتب بصورة دائرية.
- **وضع التطوير:** يعمل تلقائياً عند وجود `data/beautyhouse.db` أو ملف `.dev` أو `NOVA_DEV=1` (بدون فحص ترخيص).
